# Contract: STAROT v2 codec (Dart)

A pure class, no I/O, shaped like `lib/services/devices/ring_protocol.dart`. It must agree
byte-for-byte with `scripts/recdot_wire.py`, which generates its golden vectors.

## Obligations

| Id | Obligation | Golden source |
|---|---|---|
| C-1 | `encodeFrame(opcode, payload)` produces `55 len cmd(2 BE) payload` for totals ≤ 255 and `56 (total−256) …` for totals ≥ 257; refuses payload > 508 and a total of exactly 256 | `test_recdot_wire.py` framing tests |
| C-2 | `Framer.feed(bytes)` yields complete frames across arbitrary chunk boundaries, resynchronises on `0x55`/`0x56` after garbage, and never yields a partial frame. The legacy `0xFF` v1 sync is deliberately not honoured: the RecDot is v2-only and a stray `0xFF` would swallow real frames | `framer_splits.json`: a 3-frame stream fed whole, byte by byte, in 7-byte chunks, and behind a garbage prefix |
| C-3 | An ACK is `command & 0x8000`; `ackStatus` is payload[0]; `ackData` starts at payload[1] | `test_ack_frame_carries_status_byte_then_data` |
| C-4 | TLV groups encode `[valueLen+1][attr][value]` and decode with the same length rule; truncation is an error | TLV tests |
| C-5 | `splitCallAudio(payload)` returns speaker and mic halves per the channel bitmask; odd two-channel payload is an error | call-audio tests |
| C-6 | `parseFlashChunk(payload)` returns 3-byte big-endian offset, channel 3/4/255 semantics, 40-byte de-interleave for channel 4 | flash-chunk tests |
| C-7 | `encodeGetRecord(...)` writes little-endian int32 fields; cancel is `[01 FF]` | get-record tests |
| C-8 | `decodeAdvertisement(21 bytes)` reproduces the real iPhone capture (product 8, MACs `20:FF:36:E9:2A:64` / `…:08:E0`) | golden advert test |

## Golden vector format

`app/test/fixtures/recdot_golden/*.json`, one file per obligation group:

```json
{ "name": "bond_check", "input_hex": "5508510100000000", "expected": { "command": 20737, "payload_hex": "00000000" } }
```

Generated by `scripts/generate_recdot_vectors.py` (to be written in tasks) from
`scripts/recdot_wire.py`; the Dart tests load the JSON and must not re-derive expectations
from the Dart codec (the Limitless golden test's "mirror encoder" rule).

## G.722 decoder obligations

| Id | Obligation | Golden source |
|---|---|---|
| G-1 | 16 kHz mode: N input bytes → 2N samples, bit-exact with the ITU reference | `scripts/generate_g722_vectors.py` via the bit-exact Python package |
| G-2 | 8 kHz mode: N input bytes → N samples at 8 kHz, then 8k→16k resampled to 2N samples | same |
| G-3 | Decoder state persists across calls; `reset()` restores initial state | vectors split at frame boundaries |
| G-4 | Silence in produces silence out; a 1 kHz tone survives with < 1 dB error after decode | synthesised vectors |
